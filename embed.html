Measles in our schools

This page shows how to embed the simulator in another site. Load one script and add an element:

<script type="module" src="https://YOUR-HOST/measles-dashboard/measles-dashboard.js"></script>

<!-- Both simulators, as tabs -->
<measles-dashboard default-state="UT"></measles-dashboard>

<!-- Or just one -->
<measles-school-sim default-state="UT" hide-acknowledgements></measles-school-sim>
<measles-mixing-sim preset="default-3group"></measles-mixing-sim>

Restyle it with CSS custom properties (--md-primary, --md-font-family, --md-color-quarantine, …) and ::part(); listen to md-run-start, md-run-complete and md-school-selected events. See the README for the full list.
